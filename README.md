# 제때 (Righttime)

도착 시각에서 거꾸로 알람·준비·출발 시각을 정해 주는 지각 방지 웹앱입니다.
아침 준비 시간을 실제로 기록해서 다음 알람에 반영하고, 약속 상대에게는 도착 예정 시각만 알려 줍니다.

- **써 보기:** https://righttime-alpha.vercel.app (휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다)
- **빨리 보기:** 설정 탭 → 시연 모드. 시계가 60배로 흘러서 아침 전체를 1~2분에 볼 수 있습니다.

## 왜 만들었나

지각하는 사람은 약속까지 얼마나 남았는지, 지금 나가야 하는지를 몸으로 감지하지 못합니다. 알람을 늘려도 무뎌질 뿐입니다.
기다리는 사람은 늦는 시간보다 "미리 알려 주지 않는 것"에 더 상처받습니다.
근거 자료는 [문제 정의서](docs/PROBLEM_DEFINITION.md)와 [커뮤니티 사연 모음](docs/research)에 있습니다.

## 할 수 있는 것

| 기능 | 내용 |
|---|---|
| 시간 역산 | 도착 시각 − (이동 + 배차 대기 + 여유) = 출발, 거기서 준비 시간과 기상 시간을 빼 알람을 정합니다 |
| 아침 진행 | 기상 → 준비(단계별 타이머) → 출발(챙길 것 확인) → 이동 → 도착 기록 |
| 붉은 조명 | 출발 5분 전부터 화면 가장자리가 옅은 빨강으로 빛납니다 |
| 기록 기반 추천 | 최근 5번의 평균 + 변동의 절반으로 다음 알람을 앞당깁니다 |
| 날씨 | 출발~도착 시간대 예보로 우산·겉옷을 챙길 것에 넣습니다 (Open-Meteo) |
| 장소·대중교통 | 장소를 검색하고 대중교통 소요 시간을 가져옵니다 (카카오) |
| 일정 준비 도우미 | 안내문 글·사진을 읽어 준비물과 할 일을 정리합니다 (Claude) |
| 내 말투 | 평소 문자 몇 줄로 "늦을 것 같아요" 문구를 내 말투로 만듭니다 (Claude) |
| 알리기 | 도착 시각과 늦는 분만 담은 문구를 공유창으로 직접 보냅니다. 준비 단계는 말하지 않습니다 |
| 링크로 보기 | 준비 단계와 도착 예정을 링크로 보여 줍니다. 상대는 앱 없이 봅니다 |
| 친구 약속 방 | 초대 코드로 들어온 친구와 서로의 단계·도착 예정을 봅니다. "천천히 와요"를 보낼 수 있고, 약속 기록(✅ 지켰어요 / ⏰ 늦었어요)이 쌓입니다 |
| 사진 공유 받기 | 갤러리에서 "공유 → 제때"로 보내면 읽어서 정리합니다 (안드로이드, 설치했을 때) |
| 푸시 알림 | 앱을 닫아 둬도 기상·출발 시각에 알림이 옵니다 |

## 지키는 원칙

- 위치를 계속 추적하지 않습니다. 도착할 때 한 번만 읽고, 읽은 좌표는 저장하지 않습니다.
- 상대에게 보이는 것은 단계와 도착 예정뿐입니다. 위치, 알람 미루기, 개인 기록은 올리지 않습니다.
- 문자를 대신 보내지 않습니다. 보내는 것은 항상 사용자가 직접 누릅니다.
- 상대가 몇 번 봤는지 알리지 않습니다. 재촉하는 기능은 없습니다.
- 기록·설정·장소는 기기에만 저장합니다. 서버에 올라가는 것은 공유를 켰을 때의 단계·도착 예정과, 푸시를 켰을 때의 알림 시각뿐입니다.
- API 키는 서버 함수에만 있고 브라우저 코드에는 없습니다.

## 알려진 한계

- **알람:** 웹앱이라 알람 소리는 화면이 열려 있을 때만 납니다. 닫혀 있을 때는 푸시 알림이 오지만 소리가 없고 1분쯤 늦을 수 있습니다.
- **대중교통:** 카카오는 "지금 출발" 기준 소요 시간만 줍니다. 도착 시각 기준 조회와 배차 간격이 없어서, 배차 대기는 직접 입력합니다. 대신 아침에 자동으로 다시 조회하고, 비슷한 시간대에 조회했던 값을 계획에 씁니다.
- **아이폰:** 공유창에 앱이 뜨지 않습니다. 푸시는 홈 화면에 추가한 뒤에만 켤 수 있습니다.
- **추천 규칙:** "평균 + 변동의 절반"은 검증되지 않은 임의 규칙입니다.
- **AI:** 사진·글을 읽은 결과는 틀릴 수 있습니다. 날짜와 시각은 사용자가 눌러야 반영됩니다.
- **친구 기능:** 로그인 없이 기기마다 계정이 만들어집니다. 폰을 바꾸면 친구 목록이 이어지지 않습니다.
- **만들지 않은 것:** 소셜 로그인, 보호자-아이 모드, 네이티브 앱. 이유는 [PRD](docs/PRD.md) 8장에 있습니다.

## 실행

```bash
npm install
cp .env.example .env.local   # 값을 채운다. 비워 두면 해당 기능만 꺼진다
npm run dev
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버. `api/` 서버 함수도 함께 동작합니다 |
| `npm test` | 계산 로직 테스트 (94개) |
| `npm run typecheck` | 타입 검사 |
| `npm run lint` | 린트 (파일 300줄, 함수 50줄 규칙 포함) |
| `npm run build` | 타입 검사 후 빌드 |

환경 변수는 [.env.example](.env.example)에 이름과 설명이 있습니다. `VITE_`로 시작하지 않는 값은 서버 전용입니다.

## 구조

```
src/domain/    순수 계산. 화면·저장·서버를 모른다. 테스트는 여기에 있다
src/app/       앱 상태(useApp), 자동 동기화(공유·푸시·이동 시간 재조회), 탭 껍데기
src/features/  화면 (today, morning, records, settings, notify, share, shareTarget, push)
src/infra/     바깥과 닿는 곳 (저장, 날씨, 위치, 알람 소리, AI·카카오·공유·푸시 호출)
src/ui/        공용 부품과 아이콘
api/           서버 함수 (claude, kakao, push-run). 키는 여기서만 읽는다
supabase/      DB 설계 (shares, push_jobs, rooms, room_members)
public/        아이콘, 서비스 워커에 덧붙이는 코드 (공유 받기, 푸시)
```

의존은 안쪽으로만 향합니다: `domain` ← `features` ← `infra`.

- **프런트:** Vite, React, TypeScript, PWA (`vite-plugin-pwa`)
- **서버 함수:** Vercel Functions
- **DB:** Supabase (표는 잠그고 함수로만 드나듭니다. 계정 없음)
- **외부 API:** Claude (Anthropic SDK), 카카오맵 REST API, Open-Meteo
